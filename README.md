# Flight Planner

Browser-based flight planning, currently at the MVP 0.1 foundation milestone.

## Development

```sh
pnpm install
pnpm dev
```

## Verification

```sh
pnpm typecheck
pnpm test
pnpm build
```

See [`docs/mvp-0.1.md`](docs/mvp-0.1.md) for scope and
[`docs/conventions.md`](docs/conventions.md) for project conventions.
